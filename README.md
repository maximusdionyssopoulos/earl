# Gaffer
Your window manager for macOS.

## Idea
The main idea of Gaffer is to allow for quicker navigation with fewer keystrokes.

Unlike other window managers Gaffer does not limit a window to being in only one layout. Instead you can use window's multiple times to create different layouts of windows. A layout can even be nested inside other layouts.

Gaffer does not tile your windows automatically instead it allows for you to tile windows manually.
